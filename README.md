# Proyecto Integrador: Análisis de Comercio Exterior, Reintegros y Drawback (2020–2025)

## 📌 Datos Generales
* **Carrera:** Comercio Internacional / Despachante de Aduana
* **Tema:** Evolución de las Exportaciones Agroindustriales y Forestales e Impacto Operativo de las Normativas sobre Reintegros a la Exportación y Drawback (2020-2025).

---

## 🛠️ Herramientas Utilizadas y Metodología
1. **Perplexity:** Búsqueda e investigación de datos estadísticos oficiales de exportación y decretos/resoluciones aduaneras.
2. **Cuaderno Gemini (NotebookLM):** Procesamiento, síntesis y lectura analítica de los archivos Excel y Word.
3. **Gemini / Claude:** Estructuración de la matriz de costo aduanero y desarrollo del código web HTML/CSS/JS.
4. **Google Drive:** Almacenamiento personal de los 3 archivos de respaldo (2 Excel y 1 Word).
5. **GitHub:** Repositorio para el código fuente (`index.html`) y documentación completa del trabajo.
6. **Netlify:** Despliegue y publicación del sitio web en línea.
